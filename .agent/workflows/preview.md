# Preview Local

Abre un servidor local para previsualizar los cambios antes de hacer deploy.

## Uso
Ejecuta `/preview` para abrir la aplicación en el navegador.

## Pasos

// turbo
### 1. Iniciar live-server
```
npx live-server --port=8080 --open
```

### 2. Información
El servidor se abrirá automáticamente en `http://localhost:8080`.
Para detenerlo, usa Ctrl+C en la terminal o cierra la terminal.
