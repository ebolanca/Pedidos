# Versión App

Muestra la versión configurada en los archivos del proyecto.

## Uso

Ejecuta `/version` para verlo.

## Pasos

### 1. Consultar main.js

Leer la constante `APP_VERSION` o `CURRENT_APP_VERSION`.

### 2. Consultar index.html

Ver el badge de versión en la línea ~105.
