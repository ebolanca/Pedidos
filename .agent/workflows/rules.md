# Deploy Rules

Sube el archivo `firestore.rules` a Firebase para aplicar los cambios de seguridad.

## Uso

Ejecuta `/rules` para desplegar las reglas.

## Pasos

// turbo

### 1. Ejecutar deploy de rules

```bash
firebase deploy --only firestore:rules
```
